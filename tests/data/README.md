# Test fixtures

Trimmed Overpass responses, replayed offline by
[../test_water_osm_fixtures.py](../test_water_osm_fixtures.py). Each file keeps
only the ways that survive LOD filtering for its region, with coordinates
rounded to six decimals (~10 cm) — enough to drive the water meshers over
geometry that real OSM actually returns, small enough to live in the repo.

| File | Region | Covers |
| ---- | ------------------------------------ | ------ |
| `pyrenees_lakes.json` | Estanys de Juclar and Fontargente, Andorra | closed lake areas at LOD 2, a river at LOD 4 |
| `waal_waterways.json` | Waal floodplain, Nijmegen | 19 linear waterways + one water area at LOD 4 |
| `capetown_coast.json` | Atlantic shore below Lion's Head, Cape Town | coastline ways stitched into a sea polygon at LOD 1 |
| `waal_confluence.json` | Waal at Nijmegen, wider box | two rivers meeting, reduced to the pair whose merged ribbons left the shell non-manifold |
| `sea_polygon.json` | none — hand-written | a closed `natural=sea` area, which OSM rarely maps and no query here returned |

Each fixture carries its source bbox and a `_comment` describing provenance, so
it can be regenerated by re-running the water query for that bbox.
